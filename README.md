# ITSphere — Three.js + UDL

Versione basata sugli scenari della simulazione Three.js originale.

## Flusso
1. Cancellazione improvvisa del transfer
2. Valutazione delle alternative
3. Gestione simultanea delle priorità
4. Camera non pronta al check-in

## Funzioni aggiunte
- dialogo in sovraimpressione;
- dispense consultabili;
- analisi KPI dinamica;
- analisi UDL dinamica;
- gestione e riordino delle priorità;
- sintesi vocale;
- personaggi 3D locali;
- debrief dopo ogni decisione.

## Struttura
- `index.html`
- `style.css`
- `main.js`
- `data/scenarios.json`
- `data/resources.json`
- `models/`

Per GitHub Pages mantenere esattamente le cartelle `data/` e `models/`.


### Eventi autonomi presenti
- Cancellazione del transfer
- Arrivo di un ospite con bagaglio smarrito
- Camera non pronta al check-in
