# ITSphere — personaggi locali

File inclusi:

- `receptionist.glb` — receptionist donna con uniforme hospitality
- `guest_male.glb` — ospite uomo
- `guest_female.glb` — ospite donna

I modelli sono autonomi e non usano URL esterni, quindi GitHub Pages non incontra errori CORS.
Sono modelli 3D stilizzati a proporzioni umane, con volto, capelli, abbigliamento e nodi articolabili.
