# ITSphere — GitHub Minimal

Questa build non usa file JSON esterni e non richiede cartelle.

Carica questi file direttamente nella root del repository:

- index.html
- style.css
- main.js
- receptionist.glb
- guest_male.glb
- guest_female.glb
- .nojekyll

Scenari, dispense, KPI, UDL e priorità sono incorporati in `main.js`.

Non rinominare i file e non aggiungere `(1)`, `(2)`, ecc. ai nomi.
