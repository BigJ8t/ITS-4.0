# Modelli 3D inclusi

Questa cartella contiene i due personaggi creati appositamente per il prototipo:

- `harper.glb` — receptionist / personaggio femminile business
- `jordan.glb` — ospite / personaggio maschile business

Sono modelli leggeri e autonomi, con sembianze umane, volto, capelli, abbigliamento e nodi articolati
per testa, mandibola, braccia e gambe. Non richiedono server o CDN esterni.

`manifest.json` è già impostato con `enabled: true`.
